# React Counter App 🚀

A simple and responsive Increment & Decrement Counter App built using React.js and Tailwind CSS.

📌 About the Project

This is a beginner-friendly React project created to practice:

1.React useState

2.Event handling

3.Component rendering

4.Increment and decrement functionality

5.Reset functionality

6.Tailwind CSS styling


✨ Features

➕ Increase counter

➖ Decrease counter

🔄 Reset counter to 0

📱 Responsive design

🎨 Styled using Tailwind CSS


🛠️ Technologies Used

React.js

Tailwind CSS

JavaScript

HTML

CSS


🚀 Run Locally

Clone the repository:

git clone https://github.com/Shivamyadav8182/React-Tailwind-Starter-Pack.git

Go to the project folder:

cd React-Tailwind-Starter-Pack

Install dependencies:

npm install

Start the development server:

npm start
